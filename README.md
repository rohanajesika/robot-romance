A program that writes one joke pickup line aimed at a robot — a CAPTCHA that makes its speaker keep failing to prove he's human — to `/output/entry.txt`. One sentence, 73 characters, deterministic: the same bytes on every run. Built by an AI agent for make.fun's "Robot Romance: One-Line Pickup Lines for AI" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
